# Commercial quotation — drop point

Place the Excel quotation here, named exactly:

```
public/commercial/quotation.xlsx
```

That is the only step. On the next page load, chapter 11 — **Commercial Budget** — will:

- serve it from the **Download Excel** button, and
- render it inline below, preserving merged ranges, column widths, row heights,
  fills, fonts, alignment and borders from the workbook itself.

Multiple worksheets appear as tabs. The view is read-only by design.

Until the file is present, the chapter shows a clean note in place of the
viewer — it never renders a broken or empty table.
