# 1. What the RFP Is Actually Asking

The RFP names four qualifying categories, in a clear order of preference:

| Priority | Category | Why Entlaq values it |
|---|---|---|
| **1** | **Work at El Gouna** — explicitly "a plus" | Destination knowledge, supplier relationships, proven ability to deliver in this specific place |
| **2** | **Comparable summits** | Multi-day, multi-venue, senior audience, programme complexity |
| **3** | **Launches** | The report launch is the signature moment; launch craft is directly relevant |
| **4** | **Destination events** | Logistics, guest journey, remote delivery |

**Selection strategy:** lead with the closest match to what worries Entlaq most. Their risk is not creative — it is **whether anyone can deliver a premium multi-venue summit for 500 senior guests in El Gouna, in September, in a compressed window.** Case studies should answer that anxiety directly.

# 3. Recommended Portfolio Shape

**Four to six case studies.** Fewer looks thin; more dilutes. Each should earn its place by proving something different.

| Slot | Should prove | Ideal profile |
|---|---|---|
| **1 — The Anchor** | "We have done this exact thing" | Closest overall match — ideally a multi-venue destination summit with a senior audience |
| **2 — The Destination Proof** | "We can deliver away from base" | El Gouna work if it exists; otherwise remote/destination delivery |
| **3 — The Moment** | "We build signature reveals" | A launch with large-format LED or interactive audience integration |
| **4 — The Audience** | "We handle this level of guest" | VVIP, government, protocol, or high-security delivery |
| **5 — The Scale** *(optional)* | "500 is not large for us" | Comparable or larger scale |
| **6 — The Pressure** *(optional)* | "We deliver under compression" | Fast-turnaround project — directly answers the timeline risk |

**If El Gouna work exists in the agency's history, it leads.** The RFP calls it out explicitly, and no other credential is worth as much on this pitch.

# 5. Presentation Principles

| # | Principle | Rationale |
|---|---|---|
| 1 | **Every case study ends with an explicit relevance line** | The reader should never have to work out why they are looking at it |
| 2 | **Lead with imagery** | Production credibility is visual. A case study without strong images does not persuade. |
| 3 | **At least one hard metric each** | "Successful" is not evidence. Numbers are. |
| 4 | **Client names where permitted; sectors where not** | **[CLIENT INPUT REQUIRED]** — confidentiality position per project |
| 5 | **Consistent length** | Uniform treatment reads as a portfolio; varied length reads as padding |
| 6 | **Testimonials where available** | A client's words outperform our own |
| 7 | **Static presentation** | Per [10_information_architecture.md](10_information_architecture.md), evidence sections carry no motion. Credibility comes from stillness. |

## Decision Summary

**Decisions Made**

| Decision | Reasoning |
|---|---|
| **Four to six case studies, each proving something different** | Fewer looks thin; more dilutes. Each must earn its slot. |
| **El Gouna work leads if it exists** | The RFP explicitly names it as "a plus" — no other credential is worth as much here |
| **Ten-dimension scoring model for selection** | Removes subjectivity; ensures the portfolio collectively covers every risk Entlaq holds |
| **Mandatory relevance line on every case study** | The reader should never have to draw the parallel themselves |
| **At least one hard metric per case study** | "Successful" is not evidence |
| **Uniform template and length** | Consistency reads as a portfolio; variation reads as padding |
| **Portfolio selected against Entlaq's anxiety, not our pride** | Their risk is deliverability in El Gouna under compression — the case studies should answer that |

|---|---|
